# Adaptive Pedagogical Enrichment Generator

## Project Title
Adaptive Enrichment Activities Generator: Applying Active Learning Strategies Across Disciplines.

## Summary
The **Adaptive Enrichment Activities Generator** is an AI-powered educational tool designed to transform static curriculum topics into dynamic, diversified enrichment activities. 

Moving beyond traditional research-based tasks, this project leverages Large Language Models (LLMs) to facilitate active learning across all academic disciplines. By integrating modern pedagogical frameworks—such as Bloom's Taxonomy and inquiry-based learning—the tool empowers educators to design scaffolded, high-order thinking activities, including problem-based learning, simulations, and critical inquiry, regardless of the subject matter.

## Key Features
- **Cross-Disciplinary Application:** Designed to generate high-quality enrichment activities for any subject (Science, Humanities, Mathematics, Languages, etc.).
- **Pedagogical Alignment:** Automatically generates activities based on active learning strategies (e.g., Problem-Based Learning, Collaborative Learning, Inquiry-Based Learning).
- **Cognitive Depth:** Focuses on high-order thinking skills (Analysis, Evaluation, and Synthesis) rather than rote memorization.
- **Adaptive Design:** Allows educators to select specific pedagogical strategies tailored to diverse student needs and grade levels.
- **Clean Interface:** A professional, Streamlit-based web interface designed for educator accessibility.

## Pedagogical Foundation
This project is built upon the belief that effective learning should foster critical thinking and deep understanding. By applying evidence-based instructional strategies, the generated activities guide students to synthesize information, create solutions, and develop a deeper connection with the subject matter, transforming the classroom into an interactive learning environment.

## How It Works
1. **Input:** The educator enters the lesson topic (for any subject) and selects the target grade level.
2. **Strategy Selection:** Choose from a variety of instructional strategies (e.g., Cooperative Learning, Active Learning, Brainstorming).
3. **AI Processing:** Using the Groq API (Llama 3.3), the system generates structured, pedagogically-informed activities.
4. **Output:** The activities are presented in an organized format, including Objectives
